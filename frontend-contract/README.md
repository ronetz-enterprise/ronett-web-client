# Contrat frontend Ronet

Audit statique du backend au 22 septembre 2026. Aucun comportement applicatif n'a été modifié.

Ordre de lecture : résumé, acteurs, session, inventaire, DTO, erreurs, parcours, matrices,
roadmap, écarts, OpenAPI, tests, endpoints techniques. Exécuter ensuite les prompts dans l'ordre
`00` à `12`; chaque prompt forme un lot autonome et testable.

Les mentions **OBSERVÉ**, **PROUVÉ**, **INFÉRENCE**, **RECOMMANDATION** et **MANQUANT** indiquent
le niveau de preuve. Le fichier `endpoint-counts.txt` permet de contrôler l'exhaustivité des 136
routes inventoriées.
